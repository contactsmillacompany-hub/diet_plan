Create a highly attractive modern responsive diet planner webpage for personal use.

Design Style:

* Premium iPhone-style UI
* Extremely clean and minimal look
* Elegant spacing and typography
* Soft gradients and glassmorphism effects
* Smooth animations and transitions
* Modern card-based layout
* Visually calming and aesthetic
* High-quality polished UI similar to modern wellness apps
* Dark mode support
* Mobile-first responsive design

Main functionality:

* Automatically detect current time
* Show only the current meal section based on time:

  * Breakfast
  * Lunch
  * Evening Snacks
  * Dinner

Meal timing logic:

* 6 AM – 10 AM → Breakfast
* 10 AM – 1 PM → Snacks
* 1 PM – 4 PM → Lunch
* 4 PM – 7 PM → Evening Snacks
* 7 PM – 10 PM → Dinner

Homepage Layout:

* Current time display
* Dynamic greeting message
* Large current meal title
* Beautiful meal cards
* Small progress section
* Smooth section transitions

Meal Cards:

* Display dish names from local JSON data
* Large modern rounded cards
* Hover and tap animations
* Highlight selected dish beautifully
* Show glowing “Preparing Now” badge when selected
* Only one active dish at a time

Data:

* Meals come from a local JSON object
* No backend
* No login/signup
* Offline friendly

Example JSON:
{
"breakfast": ["Poha", "Oats", "Eggs"],
"lunch": ["Rice + Dal", "Paneer"],
"snacks": ["Fruit Bowl"],
"dinner": ["Roti + Sabzi"]
}

Tech Stack:

* HTML
* CSS
* JavaScript only

The webpage should feel:

* premium
* modern
* elegant
* lightweight
* calming
* visually addictive to use daily
